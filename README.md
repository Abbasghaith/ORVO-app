# ORVO — Social web app (UI refresh 1.1)

واجهة اجتماعية تجريبية مبنية باستخدام React وVite، بتصميم عربي RTL ومتجاوب.

## التشغيل

1. ثبّت Node.js على بيئة التطوير.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ:

   ```bash
   npm install
   npm run dev
   ```

4. للبناء والنشر:

   ```bash
   npm run build
   ```

   مجلد النشر الناتج هو `dist`.

## التصميم في الإصدار 1.1

- لوحة ألوان دافئة ومحايدة: عاجي، فحمي، زيتوني، ولمسات طينية.
- مظهر نهاري وليلي من صفحة الإعدادات، مع حفظ الاختيار محلياً على الجهاز.
- واجهة عربية RTL ومتجاوبة مع الهاتف والتابلت والحاسوب.
- بطاقات أخف وحدود هادئة ومساحات أكثر اتزاناً.

## ملاحظات مهمة

هذه نسخة واجهة أمامية تجريبية. المنشورات والتعليقات والإعجابات والمتابعة والمظهر تُحفظ محلياً في المتصفح، ولا يوجد حالياً تسجيل دخول أو مزامنة بين المستخدمين أو قاعدة بيانات أو تخزين صور على خادم. سيتم ربط Supabase في مرحلة لاحقة.
