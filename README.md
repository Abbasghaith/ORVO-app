# ORVO — Social Network UI (Version 1.0)

واجهة أولية فعلية لتطبيق تواصل اجتماعي مبسط، مبنية باستخدام React وVite.

## ما الذي يعمل حالياً؟
- التنقل بين الرئيسية والاستكشاف والإشعارات والملف الشخصي.
- الوضع الفاتح والداكن مع حفظ الاختيار على الجهاز.
- الإعجاب وإلغاء الإعجاب.
- كتابة التعليقات وإضافتها.
- إنشاء منشور نصي أو مع صورة.
- حفظ المنشورات محلياً في المتصفح.
- البحث في المنشورات.
- متابعة وإلغاء متابعة حسابات تجريبية.
- تصميم متجاوب للهاتف والتابلت والحاسوب.

## متطلبات التشغيل
- Node.js 18 أو أحدث.
- اتصال بالإنترنت لتنزيل الحزم والخطوط والصور الخارجية.

## التشغيل
```bash
npm install
npm run dev
```
افتح الرابط المحلي الذي يعرضه Vite.

## إنشاء نسخة الإنتاج
```bash
npm run build
```
سيتم إنشاء مجلد `dist`.

## ملاحظات مهمة
هذه نسخة واجهة أمامية تجريبية. لا يوجد حتى الآن:
- تسجيل دخول حقيقي.
- قاعدة بيانات أو مزامنة بين الأجهزة.
- رفع صور إلى خادم.
- إشعارات أو قصص حقيقية مشتركة بين المستخدمين.
- صلاحيات مدير أو نظام بلاغات.

المنشورات التجريبية والتفاعلات تُحفظ محلياً في متصفح الجهاز فقط. سيتم تنفيذ Supabase والحماية والنشر في المراحل اللاحقة، حسب الخطة.
